# تحديث الأرباح والخسائر والخوارزمية

أضيفت مسارات API محمية بالرمز: `GET /performance` و`GET /strategy`.

`/performance` يحسب مجموع الأرباح ومجموع الخسائر وصافي الربح المحقق ونسبة الفوز والرسوم من الصفقات المسجلة بالفعل، دون إنشاء أو تعديل بيانات الصفقات.

`/strategy` يشرح قواعد EMA12/EMA26/RSI14/ATR14 الفعلية. مسار `/trades` الموجود سابقًا يستخدمه التطبيق لعرض تفاصيل كل صفقة.

## التشغيل
1. خذ نسخة احتياطية من المشروع وقاعدة البيانات قبل التحديث.
2. استبدل ملفات المشروع بالنسخة المعدلة مع **الإبقاء على ملف `.env` المحلي**؛ لم يتم تضمينه في ZIP لحماية أسرارك.
3. في PowerShell داخل مجلد المشروع: `docker compose up -d --build --force-recreate api`
4. تحقق من `/health` ثم اختبر `/performance` و`/strategy` بترويسة `X-API-Token`.
5. افتح `android` في Android Studio ثم Sync وRun.

## تنبيهات
- لا تستخدم `docker compose down -v` لأنه يحذف بيانات PostgreSQL.
- لا تغيّر `POSTGRES_PASSWORD` دون مزامنة كلمة مرور مستخدم قاعدة البيانات الحالي.
- الربح المحقق يختلف عن التقييم اللحظي للصفقات المفتوحة.
- التطبيق يستخدم HTTP محليًا للمحاكي؛ لا تعرض API للإنترنت دون HTTPS ومصادقة مناسبة.
- التداول الحقيقي والفيوتشرز التنفيذي معطلان.
- لم يجرِ بناء Android فعلي في هذه البيئة؛ اختبر Gradle على جهازك.
