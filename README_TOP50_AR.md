# تحديث فحص أفضل 50 عملة تداول تجريبي

- يفحص أعلى 50 زوج Spot/USDT من حيث حجم التداول المقوّم بـ USDT خلال 24 ساعة على Binance، بشرط أن يكون الزوج متاحًا للتداول وحجم التداول اليومي لا يقل عن مليون USDT. يستبعد العملات المستقرة وبعض الرموز ذات الرافعة.
- تتغير القائمة كل 30 دقيقة؛ ليست قائمة ثابتة أو ضمانًا للسيولة المستقبلية.
- يفحص القائمة كل خمس دقائق عند تشغيل البوت، بحد خمسة طلبات شموع متزامنة، ويختار أعلى إشارة مستوفية للشروط.
- يعتمد على EMA12/EMA26 وRSI14 وMACD وتأكيد الحجم أو متوسط Bollinger، مع فلتر ATR. لا توجد ضمانات للربح.
- يحافظ على صفقة تجريبية واحدة مفتوحة في كل لحظة على مستوى المحفظة، مع حد التداول اليومي والانتظار بعد الإغلاق وضوابط المخاطرة الموجودة.
- يستخدم الشموع المكتملة فقط، ولا يرسل أوامر حقيقية.
- يمكن متابعة قائمة العملات من `GET /universe` والإشارات من `GET /scan` باستخدام ترويسة `X-API-Token`.
- قد يستغرق أول فحص عدة دقائق؛ ويعتمد على توفر واجهة Binance العامة.

## التشغيل
احتفظ بنسخة احتياطية من المشروع وقاعدة البيانات. انسخ ملف `.env` الخاص بك محليًا إلى المجلد الجديد، ولا تشاركه. لا تستخدم `docker compose down -v`.

```powershell
docker compose up -d --build --force-recreate api
docker compose ps
curl.exe http://localhost:8000/health
```

في تطبيق Android استخدم رمز API الحالي؛ لوحة الأرباح والخسائر وسجل الصفقات موجودان من الإصدار السابق. صفحة عرض جميع إشارات `/scan` غير مضافة إلى Android في هذه النسخة.

**قيود:** لم يُجرَ اختبار تكامل مع Binance أو تشغيل Docker أو Android في هذه البيئة. يجب اختبار المحاكاة والنتائج تاريخيًا وخارج العينة قبل أي استخدام مالي.
