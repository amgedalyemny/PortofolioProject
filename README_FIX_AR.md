# إصلاحات محاكاة التداول — إصدار محافظ

**لا توجد خوارزمية تمنع الخسائر نهائيًا.** هذا التحديث يصلح عيوب محاسبة ومحاكاة واضحة، لكنه لا يثبت أن الاستراتيجية مربحة.

## التغييرات
- عدم تسجيل صفقة مغلقة بسبب TARGET بخسارة صافية ناتجة عن كون الهدف أقل من الرسوم والانزلاق المتوقع: يرفض النظام فتح صفقة هدفها أقل من نقطة التعادل.
- حساب حجم الصفقة بناءً على مسافة وقف الخسارة مع تكلفة رسوم وانزلاق تقديرية.
- بدء فترة انتظار 15 دقيقة على الأقل من آخر إغلاق بدل الاعتماد على آخر فتح.
- استمرار مراقبة الصفقات المفتوحة حتى لو أوقفت فتح صفقات جديدة باستخدام `/stop`، طالما خدمة API تعمل.
- تنفيذ وقف الخسارة بسعر أسوأ عند القفز أسفل مستوى الوقف في محاكاة الشمعة المغلقة.
- إضافة اختبارين آليين للهدف المربح ورفض الهدف غير المجدي.

## قيود مهمة
- استراتيجية EMA/RSI/ATR كما هي؛ لم يتم إثبات جدواها على بيانات خارج العينة.
- الأسعار من الشموع المغلقة؛ وقف الخسارة لا يضمن سعر تنفيذ في سوق حقيقي، وتوقيت المحاكاة قد يختلف عن الواقع.
- الرصيد السابق وسجل الصفقات الخاسرة لا يتغيران؛ لا يتم إعادة كتابة التاريخ.
- بعض الصفقات السابقة الموسومة TARGET وخاسرة قد تكون أغلقت بسبب خطأ المحاكاة القديم؛ تحتاج تدقيقًا مستقلًا.
- لا يوجد تنفيذ تداول حقيقي أو تنفيذ عقود آجلة.

## تشغيل
1. احتفظ بنسخة احتياطية من مشروعك الحالي وقاعدة بيانات Docker.
2. **لا تنسخ `.env` إلى ملفات مشاركة عامة**؛ احتفظ بإعداداتك محليًا.
3. أوقف البوت عن فتح صفقات جديدة من التطبيق، ثم حدّث كود backend. لا توقف API مع صفقة مفتوحة دون متابعة مستقلة.
4. من مجلد المشروع: `docker compose up -d --build --force-recreate api`.
5. افحص `/health`، ثم `/status` و`/performance` بالرمز الخاص بك.
6. نفّذ الاختبارات: `cd backend; python -m pytest -q tests/test_engine.py` بعد تثبيت المتطلبات.

## توصية
لا تبدأ التداول الحقيقي. شغّل Paper Trading لفترة كافية ثم اختبر الاستراتيجية تاريخيًا مع تكاليف التداول، وانظر إلى الانخفاض الأقصى والتوقع الرياضي والنتائج خارج العينة.
